# data/sample/

A tiny **synthetic** 7-channel state tensor (`state_tensor.npy`, shape `(7, 8, 8)`) that is
intentionally committed to git so tests and the quickstart notebook run without downloading
the real datasets. It is not real remote-sensing data and should not be used for results.

Real region tensors live under `data/<region>/grids/` and are git-ignored (see `../README.md`).
