# Review history

Historical audit and review reports, kept for provenance. **They describe the repository as it
was on the date each was written** — file paths, script names, and result numbers quoted inside
them are snapshots, not current documentation. For the current state see
[`../RESULTS_FROZEN.md`](../RESULTS_FROZEN.md) and the top-level `README.md`.

| Report | Scope |
|---|---|
| `forensic_audit_report.md` | Scientific-integrity and reproducibility audit |
| `AUDIT_V2_FORENSIC_CODE_REVIEW.md` | Forensic code review of the V2 (Cell2Fire) re-founding |
| `claude_review_report.md` | Full-repository code and methodology review |
| `Chatgpt_Review.md` | Independent second-opinion review |

The findings from these reviews drove the V1 → V2 migration
([`../MIGRATION.md`](../MIGRATION.md)) and the honest reframing of the ablation results now
reported in `RESULTS_FROZEN.md`.
