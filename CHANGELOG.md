# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Changed
- **Repository restructured.** The five frozen result directories (`wildfire_phase3_multiseed/`,
  `wildfire_phase3_hiercomm_learned/`, `wildfire_phase4/`, `wildfire_phase4_extended/`,
  `wildfire_phase6/`) moved under `results/`; audit reports moved to `docs/reviews/`; authored
  supplement files moved to `docs/supplement_assets/`. Directory names are unchanged and every
  FREEZE fingerprint is computed over paths relative to its own directory, so all frozen
  artifacts verify byte-identically at the new locations.
- README rewritten: headline results, honest ablation findings, quickstart, reproduction
  commands, and repository layout.
- `.gitignore` rewritten with root-anchored rules, removing the fragile re-include stack.
- CI large-file guard now inspects tracked files rather than the whole working tree.
- `ruff` and `black` are clean across `src/`, `tests/` and `scripts/`.

### Removed
- 26 V1-era driver scripts (transfer/ablation/multiseed/phase-8 variants) that targeted
  `results/runs/` and `results/phase*_peer/` paths no longer present in the repository. The
  live pipeline is `run_phase3.py`, `run_phase4_ablations.py` and `run_phase6_transfer.py`;
  `scripts/` went from 47 entries to 21.
- `src/wildfire_marl/ablation/groups.py` — V1 result values hard-coded in Python, read only by
  the deleted scripts.
- `src/wildfire_marl/reproducibility/build_report_tables.py` — stub with an empty table
  registry, and the empty `experiments/` placeholder package.
- 539 MB of rendered GIF/MP4 rollouts untracked from `figures/` (one file alone was 69 MB and
  broke the CI large-file gate). They are regenerated by `render_phase5_gifs.py` /
  `render_phase6_transfer.py`, and the web-sized copies that ship live in
  `dashboard/public/media/`.
- 41 committed Playwright run artifacts under `dashboard/test-results/`.
- `.gitmodules`, which declared a `third_party/Cell2Fire` submodule with no gitlink in the
  index — Cell2Fire is vendored under `third_party/firehose/` instead.
- `docs/SUPPLEMENT_PLAN.md`, an executed planning document inventorying removed scripts.
- The `AAAI Template/` manuscript working directory is now git-ignored.

### Fixed
- Broken references across `README.md`, `CONTRIBUTING.md`, `data/README.md`,
  `docs/data_card.md`, `configs/marl/regimes/README.md` and `dashboard/README.md` that pointed
  at scripts and documents which no longer exist.
- `CITATION.cff` now describes the V2 (Cell2Fire / HierComm) work and matches the package
  version.

## [0.1.0] - 2026-06-26

First public, packaged release. Converts the original notebook-only research project into
an installable, reproducible repository.

### Added
- Installable `wildfire_rl` package (`pip install -e .`) with a `wildfire-rl` CLI.
- Single canonical environment (`WildfireEnv`, `MultiAgentWildfireEnv`) replacing six
  duplicated notebook environment classes.
- Single canonical `CustomCNN` (with optional pooling) replacing ~7 copies.
- Centralized metrics, evaluation loop, transfer matrix, and PPO training pipeline.
- OmegaConf config system (`configs/`) — no hardcoded paths or magic numbers.
- Reproducibility tooling: global seeding, per-env `np_random`, run metadata, sha256
  manifests, `make reproduce`.
- Baseline policies (random / no-op) and a **full symmetric** cross-region transfer matrix
  (including the previously missing California→Saudi cell).
- pytest suite, GitHub Actions CI (lint / test / install / large-file guard), pre-commit.
- Docs: architecture, reproducibility, data card, model card, development guide.
- Strict `.gitignore` / `.gitattributes` and a staged-file size guard to prevent
  accidental large-binary commits.

### Changed
- Fire-spread dynamics reimplemented as vectorized, **seeded** functions (the original used
  the unseeded global `np.random`).
- Single canonical "burned cells" threshold (was inconsistently 0.5 vs 0.2 across notebooks).

### Security
- Removed a hardcoded Google Earth Engine project id from the pipeline; credentials now come
  from environment variables (`.env`).

### Notes
- Trained checkpoints and datasets are no longer tracked in git; they are distributed via
  Hugging Face Hub / Zenodo and fetched with `scripts/fetch_models.py`.
